# 🛒 1. Superstore Sales Dashboard

Retail sales analysis across the United States.

## Features:

-   Executive overview
-   Profitability analysis
-   Discount impact analysis
-   Customer and product insights
-   Dynamic KPI selection

## Key Insights:

-   Discounts above 30% resulted in negative profit.
-   Furniture category had low profitability despite high revenue.
-   West region was the strongest performing region.

## Technologies:

Power BI \| DAX \| SQL Server \| SSMS

📁 [View Project](./Superstore-Sales-Dashboard/)

# 🚴 2. TehraanData Power BI Report

Sales, customer, and product analytics dashboard built using the
AdventureWorks dataset.

## Features:

-   Executive KPI dashboard
-   Customer segmentation
-   Product performance analysis
-   Geographic sales analysis
-   Dynamic product ranking

## Key Insights:

-   Bikes are the main revenue-driving category.
-   Customer segmentation identifies valuable customer groups.
-   Geographic analysis highlights major sales markets.

## Technologies:

Power BI \| DAX \| Data Modeling
