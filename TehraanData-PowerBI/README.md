# 📊 TehraanData Power BI Analytics Report

An interactive Power BI dashboard built to analyze sales performance,
customer behavior, product trends, and geographic insights using DAX and
business intelligence techniques.

## 🎯 Project Overview

This project transforms business data into actionable insights through
data modeling, interactive visualization, and dynamic analysis.

The dashboard focuses on: - Sales performance analysis - Customer
behavior analysis - Product and category performance - Geographic sales
insights - Dynamic business metric exploration

------------------------------------------------------------------------

# 📄 Dashboard Pages

## 1. Executive KPI Overview

A high-level view of business performance.

### KPIs:

-   Total Sales: **\$29.36M**
-   Total Orders: **28K**
-   Average Order Value: **\$1.1K**
-   Sales Per Customer: **\$1.6K**
-   Orders Per Customer: **1.5**
-   Year-over-Year Growth

### Analysis:

-   Sales by Product Subcategory
-   Sales by Country
-   Monthly Sales Trend

------------------------------------------------------------------------

## 2. Customer Analysis

Understanding customer segments and purchasing behavior.

### Features:

-   Customer distribution by country
-   Customer segmentation:
    -   Regular
    -   Gold
    -   VIP
-   Sales analysis by:
    -   Age Group
    -   Gender

------------------------------------------------------------------------

## 3. Product & Category Analysis

Analyzing product performance and category contribution.

### Features:

-   Product category comparison
-   Year-based analysis
-   Sales, quantity, freight, and tax analysis

Main categories: - Bikes - Accessories - Clothing

------------------------------------------------------------------------

## 4. Dynamic Product Analysis

Interactive product ranking and exploration.

### Features:

-   Numeric slicer for dynamic filtering
-   Product ranking based on sales
-   Subcategory performance comparison

------------------------------------------------------------------------

# 🧠 Key Insights

-   Bikes are the main revenue-driving category.
-   Geographic analysis identifies major sales markets.
-   Customer segmentation helps understand valuable customer groups.
-   Product ranking reveals top-performing products.
